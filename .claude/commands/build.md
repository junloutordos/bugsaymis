Build the frontend assets using Vite.

Usage: /build [dev|prod]

- `/build` or `/build prod` → runs `npm run build` (production build)
- `/build dev` → runs `npm run dev` (dev server, background)

Run from the project root:
```bash
npm run build
```

After building, report:
- Whether the build succeeded or failed
- Any warnings or errors from the Vite output
- The output files generated (if visible in output)
