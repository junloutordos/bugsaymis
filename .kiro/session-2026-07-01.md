## Key Patterns Learned This Session
- `toISOString()` timezone bug: never use for local date string extraction in PH timezone (+08:00)
- Ziggy routes: `@routes` in blade provides routes at runtime, but static `ziggy.js` must be regenerated after adding new named routes
- DTR computation: all break/lunch logic lives in `app/Services/HR/DTRService.php` — `getBreakMinutes()` is the central midpoint resolver
- Work schedules: `daily_schedules` is a JSON column on both `schedule_presets` and `employee_schedules` tables; structure per day: `{ time_in, time_out, lunch_start, lunch_end, work_from_home }`
